Завдання 2 

Найти максимальный элемент массива и его номер. Запишите пояснения ( Code1.c - з Міксу ) 

Пояснення: Ця програма використовується для знаходження максимального елемента і його номера за допомогою покажчиків. Спочатку відбувається введення розміру масиву через клавіатуру, заповнюється масив значеннями користувача. Потім до покажчика *pmax присвоюється перший елемент масиву. Інший покажчик *p перебирає всі інші елементи, порівнює і оновлює значення *pmax. У кінцевих функціях виводу розраховується номер максимального елемента та врешті виводиться результат.
